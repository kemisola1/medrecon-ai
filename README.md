# MedRecon AI

> Reconcile. Understand. Verify.

MedRecon AI is an agentic medication intelligence platform that
reconstructs medication histories from fragmented sources,
identifies medication discrepancies, screens for potential
medication-safety signals, and provides evidence-backed findings
for qualified human review.

## Status

🚧 Hackathon MVP — In active development

## Core Workflow

Sources
→ Extraction
→ Medication Identity
→ Timeline
→ Reconciliation
→ Discrepancy Detection
→ Interaction Screening
→ Verification
→ Prioritization
→ Human Review

## Repository Structure

- `backend/` — API and agent services
- `frontend/` — web application
- `data/` — synthetic evaluation data
- `docs/` — architecture and experiment documentation
- `scripts/` — evaluation and development utilities

## Safety

MedRecon is a decision-support prototype.

It does not prescribe, discontinue, or modify medications
and does not replace qualified clinical judgment.
